# Oct 23 fix list — what changed

Everything below is live on `https://www.igamingubuntu.com` (Vercel production,
commit `main`). `docs/analytics.md` covers the GA4/GTM details.

## Priority 1 — content quality and trust

1. **Demo posts removed.** The 10 hardcoded articles are gone from the code and
   from the seed data (the CMS "Seed database" page was deleted, and
   `/api/seed` no longer seeds anything).
   - Each URL 301-redirects to `/blog` (`next.config.ts`).
   - They are filtered out of every query, feed and sitemap
     (`src/lib/site.ts` → `REMOVED_DEMO_SLUGS`).
   - The hardcoded article lists on `/kenya`, `/nigeria`, `/ghana`,
     `/south-africa`, `/tanzania`, `/guides` were replaced with real CMS
     articles (server rendered, with empty states).
   - Fake "views" counters removed everywhere on the public site. Views now come
     from the CMS only and are hidden until they are above zero. Views are
     incremented server-side (`/api/track-view`) because Firestore rules block
     writes from the browser; the owner's own visits are not counted.
2. **Placeholder offer boxes hidden.** `AffiliateBanner`/`AffiliateBox` only
   render offers that come from the CMS "Affiliate Links" section (an offer
   needs a `linkId`, i.e. a `/go/...` link, and must not be paused/expired).
   The SportPesa / 1xBet / Betika placeholders have no `linkId`, so the sidebar
   "Top Offers", the in-article "Best Odds & Betting Offers" and the top banner
   render nothing at all — no "Sponsored"/"Affiliate link" labels, no fake tags.

## Priority 2 — crawling and indexing

3. **`/blog` pagination is crawlable.** Server-rendered pages with real
   `<a href="/blog?page=N">` links, category pills are links too, and each page
   canonicalises to itself (`/blog?page=2` → itself, not `/blog`).
4. **Homepage** server-renders the latest **12** published articles as plain
   `<a href="/blog/slug">` links.
5. **Related articles** are now automatic: under every article, 4 links chosen
   same-country first, then same category, newest first
   (`getRelatedArticles` in `src/lib/serverArticles.ts`). Server-rendered.
6. **Real 404s.** Unknown `/blog/<slug>` returns HTTP 404 via `notFound()`. The
   old soft 404 was caused by the root `loading.tsx` Suspense boundary flushing
   a 200 before the lookup finished; that file was removed (that was the actual
   root cause of the 200s).

## Priority 3 — SEO details

7. **Static page metadata.** `/about`, `/advertise`, `/affiliate-disclosure`,
   `/contact`, `/editing-services`, `/global`, `/link-building-services`,
   `/privacy`, `/seo-content-writing`, `/services`, `/terms`,
   `/translation-services`, `/work-with-me` each have a self-referencing
   canonical on `https://www.igamingubuntu.com`, their own title and their own
   meta description (metadata lives in a `layout.tsx` per route, because the
   pages themselves are client components).
8. **Sitemaps use real dates.** Static pages use a fixed `2026-10-23`;
   articles use their CMS `updatedAt`. Removed demo posts never appear.
9. **Apex → www.** `http(s)://igamingubuntu.com` now redirects to
   `https://www.igamingubuntu.com` (308). Vercel still answers the plain-HTTP
   request with its own HTTPS upgrade first, so the chain is 2 hops until the
   domain setting below is changed. See "Still needs a click".

## Priority 4 — advertising and analytics

10. **`/advertise` rewritten** with the supplied copy, contact form kept.
    Articles with status `sponsored` or `press-release` now get
    `rel="sponsored noopener"` (and `target="_blank"`) on every external link
    automatically (`withSponsoredLinks` in `src/lib/contentHtml.ts`), plus a
    "Sponsored"/"Press release" label.
11. **`/ads.txt`** is served from `src/app/ads.txt/route.ts`:
    `google.com, pub-5956809831211575, DIRECT, f08c47fec0942fa0`.
12. **GA4 lead events.** `generate_lead` with `form_name` contact / newsletter /
    advertise / quote, sent only after a successful submit.
13. **Owner traffic.** GA4 is never loaded on `/igub-cms-x7k9/*`. A successful
    CMS login sets `igub_internal=1` (1 year); while it is present every hit
    carries `traffic_type: "internal"`.
14. **No double counting in code.** One loader, one `config` call with
    `send_page_view: false`, one `page_view` per navigation. The GTM container
    still has to be checked by hand (see "Still needs a click").

## Priority 5 — CMS

15. **Draft badge.** Articles with no `status` (legacy drafts) now show
    **Draft** in the articles list, and the "Draft" filter matches them.
